# 🚀 Roadmap PWA - Portail Evan Patruno

Ce document liste les idées d'améliorations pour le portail client, classées par complexité technique.

## 🟢 Niveau : Facile (Cosmétique & Micro-interactions)
1.  **Skeleton Screens** : Afficher des blocs animés pendant le chargement des données.
2.  **Salutation Dynamique** : Adapter le message selon l'heure (Bonjour/Bonsoir).
3.  **Pull-to-Refresh** : Rafraîchir les données en tirant vers le bas.
4.  **Barre de progression circulaire** : Indicateur visuel pour la checklist (ex: 75%).
5.  **Haptique sur les Jalons** : Vibration lors de la validation d'une étape.
6.  **Confirmer la Déconnexion** : Modale stylisée à la place du `confirm()` navigateur.
7.  **Auto-focus MLS** : Focus automatique sur l'input Centris à l'ouverture de la section.
8.  **Descriptions de Timeline** : Info-bulles explicatives sur chaque étape.
9.  **États de survol (Hover)** : Effets de brillance (glow) plus dynamiques au toucher.
10. **Bouton "Remonter"** : Navigation rapide en haut de page pour les longs historiques.

## 🟡 Niveau : Moyen (Fonctionnalités PWA & UX)
11. **Exportation VCF** : Téléchargement direct de la fiche contact d'Evan.
12. **Bannière de mise à jour** : Notification de nouvelle version disponible.
13. **Ajout au Calendrier** : Synchroniser les visites avec Google/Apple Calendar.
14. **Mode Sombre / Clair** : Bascule de thème selon la préférence utilisateur.
15. **Filtres de Visites** : Trier les visites par statut (Prévues, Confirmées, Terminées).
16. **Lecteur PDF intégré** : Visualisation des guides d'achat/vente sans quitter l'app.
17. **Multi-langue** : Support complet Français / Anglais.
18. **Lien de partage spécialisé** : Générer des fiches de propriétés avec prévisualisation.
19. **Bulle Vidéo** : Vidéos courtes d'Evan expliquant les étapes clés.
20. **Calculatrice Hypothécaire** : Outil de simulation intégré au portail.

## 🔴 Niveau : Avancé (Data, Sécurité & Automation)
21. **Déverrouillage Biométrique** : Utilisation de FaceID / TouchID via WebAuthn.
22. **Background Sync** : Envoi différé des avis de visite en cas de perte de réseau.
23. **Upload de documents** : Envoi de documents (lettre de banque, etc.) vers Zoho.
24. **Notifications Push Auto** : Alertes automatiques déclenchées par le CRM.
25. **Chat en direct** : Intégration WhatsApp ou chat privé propriétaire.
26. **Suivi des Partenaires** : Dashboard restreint pour les partenaires experts.
27. **Statistiques de Marché** : Graphiques de prix locaux basés sur les données réelles.
28. **Deep Linking Notifications** : Pointer vers une visite spécifique via une notification.
29. **Assistant IA FAQ** : Chatbot intelligent pour les questions immobilières 24/7.
30. **Rapport de visites PDF** : Génération d'un récapitulatif complet des visites effectuées.
